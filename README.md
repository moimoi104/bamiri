# バミリ

ダンスのフォーメーションを「シーン」ごとに作って、シーンごとに音源をつけるアプリです。
スマホ（iPhone / Android）・iPad・パソコンのブラウザで動き、作品はその端末に保存されます。

## 使い方

1. アプリを開くと、前回の作品がすぐ開きます（左上の「☰ 作品」で保存した作品の一覧）
2. ダンサーをドラッグして立ち位置を決める（「横一列」「縦一列」で一発で並ぶ）
3. 下の「＋ シーン」でシーンを追加。そのとき流す音源を選ぶ（なしも可）
4. ▶ で再生すると、シーンごとに音源が頭から流れ、シーンが終わると次へ進みます
   - シーンの長さ：音源の長さ（音なしは8秒）。シーンの「⋯」で秒数を変更できます
5. 「練習」で自分をタップすると、自分の位置と次の移動先が目立ちます

## メンバーに送る

「送る」→「作品ファイル（音源・写真入り）」→「LINEなどで送る」。
受け取った人はアプリの「☰ 作品」→「ファイルを開く」で、音源ごと開けます。
PDF や練習動画（音つき）も「送る」から作れます。

ホーム画面に追加するとアプリのように使えます（iPhone: Safari の共有ボタン →「ホーム画面に追加」）。
